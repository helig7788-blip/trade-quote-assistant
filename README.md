# 外贸询盘到报价 SOP 设计与 AI 辅助报价工作台

基于 Dify 工作流的 AI 报价工具。输入客户询盘邮件，自动提取产品型号、数量、港口、交期，核算价格，生成英文报价单草稿。

## 项目背景

外贸业务员每天收到大量询盘邮件，需要手动提取信息、查成本表、写报价单，重复耗时且容易出错。本项目用 AI 自动完成前三步，业务员只需核对和发送。

## 核心能力

- 从非结构化邮件中提取产品型号、数量、港口、交期
- 读取成本表，按公式核算单价和总价
- 生成英文报价单草稿，注明有效期 7 天
- 异常场景处理：型号不存在、数量低于起订量、交期为空

## AI 方案设计

| 环节     | 用什么 | 为什么                 |
| ------ | --- | ------------------- |
| 信息提取   | AI  | 自然语言理解，AI 擅长        |
| 价格核算   | 代码  | 涉及利润，必须用公式，AI 不能编数字 |
| 报价单生成  | AI  | 文案生成，AI 擅长          |
| 最终报价确认 | 人工  | 必须业务员审核后才能发出        |

## 工作流结构

开始 → 参数提取器 → 代码执行 → LLM → 输出

## 已知限制

- 当前成本表只包含 3 个产品型号，实际使用需替换为真实成本表。
- 不支持多产品同时报价。
- 报价单为草稿，必须由业务员审核后才能发出。
